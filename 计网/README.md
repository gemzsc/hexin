# 局域网数据包捕获与分析程序

这是计算机网络课程实践项目，用于捕获和分析局域网数据包，并通过图形界面查看数据包内容。

## 功能

- 捕获以太网帧
- 解析 Ethernet、ARP、IP、TCP、UDP 和 ICMP 协议
- 在图形界面中查看数据包列表和协议字段
- 查看数据包的十六进制原始数据
- 保存和加载 PCAP 文件，可使用 Wireshark 打开
- 按协议过滤数据包，并支持列表排序
- 生成示例数据，用于功能演示

## 运行环境

- Windows 10/11
- Python 3.8 或更高版本
- Scapy
- Npcap（实时捕获需要）
- 管理员权限（实时捕获需要）

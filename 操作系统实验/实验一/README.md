# 实验一：进程的状态转换

本实验使用 C++ 编写进程状态转换模拟程序，用于观察进程在运行过程中的状态变化，并了解进程控制块（PCB）和有限内存容量对进程调度的影响。

## 实验内容

程序为每个进程记录 PID、名称、优先级、当前状态、已运行时间和所需运行时间。支持创建进程、显示进程列表、手动切换合法状态、逐步自动调度，以及连续运行模拟。

状态模型包括新建、就绪、运行、阻塞、挂起就绪、挂起阻塞和终止。模拟内存容量以可驻留的活跃进程数量表示，默认上限为 4；超出容量的新进程保留在新建态，进程结束或挂起释放容量后会接纳等待的新建进程。

## 编译与运行

要求 Windows 和 MinGW-w64 g++。在本实验目录的 PowerShell 终端运行：

```powershell
g++ -std=c++11 .\Experiment1.cpp -o .\Experiment1.exe
.\Experiment1.exe
```

在菜单中可以创建进程、查看状态、手动执行状态转换、自动运行一步或连续运行。手动转换时输入目标状态编号；连续运行时按回车继续，输入 `q` 停止。

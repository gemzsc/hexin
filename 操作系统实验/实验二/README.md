# 实验二：进程（作业）调度算法的设计与实现

本实验使用 C++ 编写进程调度模拟程序，用于观察不同调度算法下作业的执行顺序，并比较周转时间、带权周转时间等性能指标。程序从 `processes.txt` 读取作业信息，并分别运行多种调度算法。

## 实验内容

程序为每个作业记录名称、到达时间、服务时间、优先级、截止时间和周期。支持 FCFS、SJF（非抢占）、PSA（非抢占优先级）、HRRN、RR（时间片轮转）、抢占式优先级、EDF 和 LLF 调度。

程序输出各算法的调度时间线、每个作业的完成时间、周转时间和带权周转时间，以及平均周转时间和平均带权周转时间。RR 分别使用时间片 `q=1`、`q=2` 和 `q=4` 进行比较。EDF 和 LLF 会逐时刻显示就绪队列与调度决策，LLF 同时显示松弛度。

输入文件 `processes.txt` 每行包含六列：

```text
进程名 到达时间 服务时间 优先级 截止时间 周期
```

当前实现将非负截止时间视为绝对截止时刻，每行表示一次作业释放；周期字段会读取，但不会用于重复释放。

## 编译与运行

要求 Windows 和 MinGW-w64 g++。在本实验目录的 PowerShell 终端运行：

```powershell
g++ -std=c++11 .\Experiment2.cpp -o .\Experiment2.exe
.\Experiment2.exe
```

确保 `processes.txt` 与 `Experiment2.exe` 位于当前目录，运行后程序会依次显示各调度算法的结果。

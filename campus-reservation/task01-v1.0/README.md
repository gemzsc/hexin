# 校园资源预约系统 任务1 V1.0

本目录保存课程实践的第一个独立版本。它是一个基于 JDK 8 的控制台登录程序，用于验证程序入口、键盘输入、字符串比较和条件分支。后续版本以本版为起点逐步增加功能。

## 已实现功能

- 从控制台输入账号和密码，一次运行处理一次登录。
- 识别两组固定测试账号，并输出对应身份的欢迎信息。
- 其他账号或密码组合输出统一的失败提示。

| 身份 | 测试账号 | 测试密码 |
| --- | --- | --- |
| 管理员 | `admin` | `123456` |
| 学生 | `student` | `123456` |

这些账号仅用于课程演示，不应当用作真实系统的账号配置。

## 运行方法

环境：JDK 8。源码文件为 [`src/SystemMain.java`](./src/SystemMain.java)。

在本目录打开终端，执行：

```bash
javac -encoding UTF-8 -d out src/SystemMain.java
java -cp out SystemMain
```

也可以在 IntelliJ IDEA 中将本目录作为 Java 项目打开，并运行 `SystemMain.main`。`out/` 是编译输出目录，已被仓库忽略。

## 验收记录

| 输入账号 | 输入密码 | 预期结果 |
| --- | --- | --- |
| `admin` | `123456` | 管理员登录成功 |
| `student` | `123456` | 学生登录成功 |
| `admin` | `wrong` | 登录失败 |
| `unknown` | `123456` | 登录失败 |
| 空输入 | 空输入 | 登录失败 |

本版已由开发者手动检验通过。程序只执行一次登录；失败提示后不会自动重新输入。

## 设计与下一步

当前按照任务1要求，将交互与校验逻辑保留在 `SystemMain` 中，使用 `Scanner` 读取输入，通过 `String.equals()` 比较内容，并用 `if / else if / else` 保证一次登录只产生一种结果。固定账号使程序无法注册新用户，且重启后没有用户数据可保存。任务2 V1.1 将从本版增量开发，引入登录与注册菜单、`HashMap<String, String>` 用户集合和输入校验。

# 高校学生管理系统

这是《C++程序设计》课程实践项目，使用 C++ 编写的控制台学生管理系统。系统按教务秘书、教师和学生三种角色提供不同功能，并将学生及课程成绩保存到本地文件。

## 功能

### 教务秘书

- 添加、查看、查询、修改和删除学生信息
- 按学号、总分或平均分排序
- 按学院、专业、班级或籍贯统计学生人数
- 根据姓名关键字模糊查询
- 分析平均分优秀率和挂科率
- 按学院查看各课程的挂科人数分布

### 教师

- 查看学生信息和课程成绩
- 登记新课程成绩
- 修改已有课程成绩

### 学生

- 登录并查看个人信息及课程成绩

## 项目结构

| 文件 | 说明 |
| --- | --- |
| `main.cpp` | 程序入口、主菜单和角色菜单 |
| `Manager.cpp`、`Manager.h` | 用户登录、学生管理、统计分析和文件读写 |
| `Student.cpp`、`Student.h` | 学生信息与成绩管理 |
| `Course.cpp`、`Course.h` | 课程名称、成绩和学期信息 |
| `utils.h` | 密码输入等辅助功能 |
| `data.txt` | 学生和课程数据文件 |

## 运行环境

- Windows
- Visual Studio，安装“使用 C++ 的桌面开发”组件
- 项目使用 C++20 标准

## 编译与运行

1. 使用 Visual Studio 打开 `StudentSystem.vcxproj`。
2. 选择 `Debug` 或 `Release` 配置，以及 `x64` 平台。
3. 生成并运行项目。

程序从当前工作目录读取 `data.txt`。退出程序时会将数据保存到该文件；运行时请确保程序对该目录有读写权限。

## 数据格式说明

学生信息和课程成绩保存在 `data.txt` 中。当前文件格式以空格分隔字段，因此学生信息中的字段不能包含空格。

## 注意事项

- 教务秘书和教师的演示账号在源码中固定设置；修改账号信息请查看 `Manager.cpp` 中的登录函数。
- 当前版本将学生密码以明文形式写入 `data.txt`，仅适合课程演示和本地练习，不适合存放真实个人信息或用于生产环境。
- 请勿将包含真实学生信息或密码的 `data.txt` 上传到公开仓库。
